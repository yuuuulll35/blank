# BLANK

NPC·PC 대사와 나레이션을 붙여 넣어 대화 로그를 한 장의 이미지로 저장하거나, 블로그(티스토리 등)에 붙여넣을 HTML로 복사하는 편집기 — 단일 HTML 파일.

**https://yuuuulll35.github.io/blank/**

## 사용법

1. **대화 넣기** 탭에 대화를 붙여 넣고 **적용하기**
2. **편집** 탭에서 문단을 고르고, 끌어서 순서를 바꾸고, 화자·서식을 고친다
3. **스타일** 탭에서 모양·색·글꼴·간격을 고른다
4. **이미지 저장** 또는 **HTML 복사**
